# Sharp AC Gateway for Home Assistant

Home Assistant App catalog for Sharp AC Gateway. The App connects compatible
Sharp air conditioners to Home Assistant through MQTT discovery.

This catalog contains installation metadata and user documentation. The App
source code and container images are distributed privately. Access to this
catalog alone does not grant permission to download the image; an authorized
installation needs private registry access configured in Home Assistant.

See the [App overview](sharp_ac_gateway/README.md) and
[configuration guide](sharp_ac_gateway/DOCS.md).

Published catalog versions use prebuilt images. Home Assistant Supervisor
manages installation and updates. Moving an existing Local App to this catalog
requires a separately verified migration; installing a second copy is not a
migration.

This is a third-party App, not an official Home Assistant or Sharp product.
